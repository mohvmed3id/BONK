# BONK (نسخة معدّلة) — Minecraft Java 26.3 / Fabric

نسخة معدّلة من مود [BONK](https://modrinth.com/mod/villager-bonk) (رخصة MIT، لـ Oli و Alve Svarén).

## الجديد في النسخة دي
1. **بتستهلك متانة الأداة**: كل ضربة ناجحة بالجاروف أو الـ Mace بتنقّص 1 من المتانة. في الـ Creative مفيش استهلاك.
2. **زرار C**: بص على القروي وأنت ماسك جاروف أو Mace، ودوس **C**، فالعروض تتغيّر من غير ما تضربه. تقدر تغيّر الزرار من Options ← Controls ← Key Binds ← BONK.
3. **شغال على Minecraft 26.3** (Fabric Loader 0.20.1+، Fabric API، Java 25).

## السلوك الأصلي (زي ما هو)
- **الجاروف**: بيغيّر العروض، بس لو القروي ليه مهنة ولسه محدش اتاجر معاه.
- **الـ Mace**: بيمسح العروض والخبرة والسمعة (gossips)، والقروي بيغمى عليه شوية.

## التثبيت
- **سنجل بلاير**: حط `bonk-*.jar` و Fabric API في فولدر `mods`.
- **سيرفر**: حطه على السيرفر. الضرب بالأداة شغال لكل اللاعيبة حتى لو معندهمش المود. زرار C بيحتاج إن اللاعب نفسه يكون مسطّب المود عنده كمان.

## البناء (Build)

### الطريقة 1: من GitHub من غير ما تسطّب حاجة
1. اعمل repository جديد على GitHub وارفع عليه كل الملفات دي.
2. ادخل على تبويب **Actions**، وهتلاقي الـ build شغال لوحده.
3. لما يخلص، افتحه ونزّل **Artifacts**، وجواه ملف الـ `.jar`.

### الطريقة 2: على جهازك
1. سطّب **JDK 25**، مثلاً من [Adoptium](https://adoptium.net).
2. افتح الفولدر في الـ terminal واكتب:
   - ويندوز: `gradlew.bat build`
   - لينكس أو ماك: `./gradlew build`
3. الملف هيطلع في `build/libs/bonk-1.2.0+mc26.3.jar`.
